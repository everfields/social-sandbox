# code-card (sandbox sample)

- **Audience:** dog owners.
- **Promise:** a number that changes what you thought.
- **Hook:** the belief it breaks, in the first second.
- **Look:** type and numbers drawn by code, no models. The source is on screen.
- **Sound:** a pad made by code.
- **Reason to follow:** a surprising number every time.
- **Never:** a number without its source.

A sandbox format, to prove the PC side. Not approved for any company.
